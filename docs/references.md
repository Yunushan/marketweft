# Reference capabilities

Reviewed public product documentation and project READMEs on 2026-11-25. The observations below describe the publishers' claims. The requirement column points to independently specified behavior and acceptance criteria in [coverage.md](coverage.md). It does not establish an upstream project's license, entitlement to its data, or MarketWeft parity. Names with several matches are identified by repository owner.

| Reference | Publicly documented workflow | MarketWeft requirement |
| --- | --- | --- |
| TradingView Ultimate | Link multiple charts in a tab, set custom intervals, replay bars and display several studies. Plan limits and exchange entitlements vary. [Plan comparison](https://www.tradingview.com/pricing/) | MW-006, MW-012, MW-013, MW-014 |
| TrendSpider | Display higher-timeframe studies and trendlines on a lower-timeframe chart. Use timeframe-specific conditions in scans and alerts. [Multi-timeframe analysis](https://help.trendspider.com/kb/automated-technical-analysis/multi-timeframe-analysis) | MW-013, MW-018, MW-027 |
| GoCharting | Analyze executed volume by price using footprint charts and compare auction activity through market profiles. [Order-flow guide](https://gocharting.com/docs/orderflow/orderflow-in-gocharting) | MW-019 |
| TakeProfit | Edit chart studies and strategies in Indie, set indicator inputs and plot results. [Language guide](https://takeprofit.com/docs/indie/What-is-Indie) | MW-015, MW-016 |
| Webull | Use simulated cash to practice order types and inspect account performance. Available order types differ by client and account mode. [Paper trading guide](https://www.webull.com/help/faq/11069) | MW-021, MW-022 |
| Investing.com | Filter economic releases and compare published values with forecasts and prior readings. [Economic calendar](https://www.investing.com/economic-calendar/) | MW-024 |
| Barchart | Build screens using technical or fundamental criteria and narrow a universe to symbols for investigation. [Barchart screener workshop](https://www.barchart.com/media/education/pdf/Smarter%20Trading-Leveraging%20Barchart%27s%20Screeners%20for%20Day%20and%20Swing%20Trades.pdf) | MW-018 |
| StockCharts | Define technical scan criteria and use those conditions in recurring alerts. [Technical alerts](https://help.stockcharts.com/scanning-and-alerts/technical-alerts) | MW-018, MW-027 |
| Koyfin | Compare prices, margins, valuation multiples and historical metrics across a watchlist or screened universe. [Data overview](https://www.koyfin.com/help/data-overview/), [historical columns](https://www.koyfin.com/help/release-notes/v3-67-historic-data-in-watchlist-screener/) | MW-018, MW-023 |
| ProRealTime | Develop a trading system, simulate it on price history and activate it separately in paper or automatic trading. [Trading systems](https://www.prorealtime.com/en/help-manual/create-trading-systems) | MW-020, MW-021, MW-022 |
| Finviz | Inspect a market map and compare securities across industry groups by relative size and color. [Market map](https://finviz.com/map) | MW-018 |
| OpenAlgo | Place broker-specific integrations behind a common API with separate operations for quotes, positions and orders. [Project documentation](https://docs.openalgo.in/) | MW-009, MW-022, MW-028 |
| Tradoor | Combine crypto order books, footprints, TPO, scripting and a paper account within a browser terminal. [tradoor-terminal/tradoor](https://github.com/tradoor-terminal/tradoor) | MW-015, MW-019, MW-021 |
| Quant Terminal | The jgt87 project documents alternate bar constructions, chart panes, custom intervals, order simulation and replay. [jgt87/quant-terminal](https://github.com/jgt87/quant-terminal) | MW-012, MW-013, MW-014, MW-021 |
| Freqtrade | Compare baseline and sliced backtests to detect signals that incorporate future information. [Lookahead analysis](https://www.freqtrade.io/en/latest/lookahead-analysis/) | MW-020 |
| Hummingbot | Controllers consume market data and instruct independent execution components. Strategies can be configured separately from connectors. [Strategy V2 architecture](https://hummingbot.org/strategies/v2-strategies/) | MW-016, MW-022, MW-028 |
| Jesse | Run strategies over historical markets with fees and inspect drawdowns. Shuffle trade sequences or vary market paths to study sensitivity. [Backtest](https://docs.jesse.trade/docs/backtest/), [Monte Carlo](https://docs.jesse.trade/docs/monte-carlo/) | MW-020, MW-025 |
| Kandle | An MCP integration lets a client read chart context, draw levels and work with studies. [Kernel-Hunter/kandle](https://github.com/Kernel-Hunter/kandle) | MW-014, MW-015, MW-028 |
| Aggr.trade | Aggregate trades from several venues and chart the resulting trade flow. [Tucsky/aggr](https://github.com/Tucsky/aggr) | MW-019 |
| OpenCharts | Self-host browser charting, drawing tools and indicator overlays. [dylanpersonguy/OpenCharts](https://github.com/dylanpersonguy/OpenCharts) | MW-006, MW-012, MW-014 |
| TradeOps | Pair chart-based crypto observation with a simulated account. The project identifies on-chain analytics as roadmap work. [kylerobertschuster/tradeops](https://github.com/kylerobertschuster/tradeops) | MW-006, MW-021 |
| Opentern | Run local charts and use a script editor, strategy reports, alerts and replayable research workflows. [ahaan-shah/opentern](https://github.com/ahaan-shah/opentern) | MW-015, MW-020, MW-027 |
| Wickline | Extend charts with JavaScript studies and strategies and backtest them in a desktop research interface. [keptaduona/wickline](https://github.com/keptaduona/wickline) | MW-010, MW-015, MW-020 |
