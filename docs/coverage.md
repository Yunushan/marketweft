# MarketWeft requirements and acceptance evidence

The evidence column tracks delivery through 0.21.0. “Backlog” identifies behavior that still needs implementation and verification. See the [test results](verification.md) and [reference product inventory](references.md).

| ID | Behavior and acceptance criterion | Evidence or next test |
| --- | --- | --- |
| MW-001 | Canonicalize venue and symbol to a stable key. The same ticker on two venues must remain distinct. | Implemented. Rust identity tests and the Wasm bridge suite. |
| MW-002 | Ingest one ordered UTC OHLCV series atomically. Reject malformed dates, reversed ranges, duplicates, negative volume and excess precision. | Implemented. Parser fixtures, calendar boundaries, import error cases and 100,000-bar boundary tests. |
| MW-003 | Compute simple moving averages over fixed-point closes. Emit a missing value until the full window is available. | Implemented. Six-place golden vector, rolling-vs-naive property checks and prefix invariance. |
| MW-004 | Compute an exponentially weighted average seeded by the first full window. Round half away from zero each step. | Implemented. Golden vectors, independent recurrence and negative rounding cases. |
| MW-005 | The browser and native code must use the same implementation. | Implemented. Rust builds as a native library and Wasm. The Node tests call the browser-facing TypeScript wrapper. |
| MW-006 | Inspect a historical chart with candles, volume and price overlays. Change the visible range and inspect an individual bar. | Browser terminal. See the tested interactions in verification.md. |
| MW-007 | Select an instrument from a watchlist, import locally and reload the saved workspace. Migrate, export and restore settings and every imported OHLCV tick. | 0.2.0 IndexedDB transactions and versioned workspace backups. In 0.24.0 each chart also exports exact OHLCV or a research CSV with provenance and indicators. The browser checks offline export and reimport. [Chart workspace](chart-workspace.md). |
| MW-008 | Open the production browser build offline after its initial asset cache completes. | Manifest and versioned service-worker cache. Offline reload is a browser acceptance case. |
| MW-009 | Read a versioned trading-bot status, account and position view. Preserve absent observations and expose runtime capabilities. | Independent observation SDK. See [trading-bot.md](trading-bot.md) for pinned upstream behavior and tests. |
| MW-010 | Start the same terminal in a Tauri desktop window without granting shell, filesystem or broker permissions. | Wrapper and native CI build path. See [platforms.md](platforms.md) before making a binary support claim. |
| MW-011 | Build from lockfiles, inventory each dependency, check licenses, scan advisories and test on proposed release hosts. | CI configured. Local gate results and gaps in verification.md. |
| MW-012 | Restore multiple chart panes with independent series and linked crosshairs. Validate 35 distinct chart types against per-type fixtures. | 0.21.0 persists two independent series and overlays with exact UTC crosshair matching. By 0.26.0, panes independently support candles, a close line and OHLC bars. Fixtures verify line and OHLC geometry, range changes and backup restore. [Chart workspace](chart-workspace.md). |
| MW-013 | Build custom timeframes, tick bars, replay and multi-symbol studies without leaking future values. | 0.3.0 replays one imported fixed-interval series against dated sessions. Chart research supports fixed-duration UTC and session-anchored aggregation. Recorded tick bars respect capture order, observation cutoffs and exact sequence IDs. Multi-symbol studies are open. [Replay](historical-replay.md) · [Chart workspace](chart-workspace.md) · [Recorded tick bars](recorded-tick-bars.md). |
| MW-014 | Save editable drawings in data coordinates. Maintain an inventory of 150 distinct tools and 600 distinct built-in indicators. | 0.22.0 implements one editable measurement tool with exact UTC and price anchors saved per instrument. In 0.23.0 the two implemented indicators have independently saved periods for each pane. Expand the inventories with individually specified and verified tools and studies. [Chart workspace](chart-workspace.md). |
| MW-015 | Specify an open time-series language with deterministic missing values, bounded evaluation and isolated plugins. | Backlog. Publish grammar, interpreter conformance vectors and quota tests before accepting user programs. |
| MW-016 | Support custom financial/statistical formulas and Rust, TS, Python and Wasm SDKs. | Partial TS observation package. Future SDKs must exchange identical typed input and output fixtures and expose version negotiation. |
| MW-017 | Track exchange sessions, action adjustments and point-in-time membership. | Membership and delisting use independent effective and observation cutoffs. Delisting proceeds and split corrections preserve stable IDs. Dividend entitlements use dated holdings. Portfolio replay keeps the resulting dividends and delisting amounts distinct by listing and currency. [Universe membership](universe-membership.md) · [Delisting proceeds](delisting-proceeds.md) · [Cash dividends](cash-dividends.md) · [Stock splits](corporate-actions.md) · [Portfolio replay](portfolio-replay.md). |

[Screen contract](universe-screen.md) · [Heatmap contract](sector-heatmap.md). |

| MW-020 | Backtest and optimize strategies with fees, slippage, execution delays and survivorship controls. | The bar backtest executes SMA signals through the paper ledger, with rolling parameter selection and disjoint tests. 0.20.0 values delisted holdings in a separate portfolio replay. [Bar backtest](bar-backtest.md) · [Walk-forward validation](walk-forward.md) · [Portfolio replay](portfolio-replay.md). |
| MW-021 | Run an isolated paper ledger with fees, position limits, exposure caps, idempotency and kill switch. | 0.13.0 replays supplied limit orders, fills and controls with exact reserves and fees, a committed-cost cap and kill switch. | MW-022 | Gate live execution by operator authorization and deterministic risk decisions. | Backlog. Prove a read-only or AI client cannot escalate, retry or bypass limits. Require venue-specific acceptance evidence. |

| MW-025 | Run walk-forward optimization and seeded Monte Carlo, report drawdown, exposure and portfolio risk. | Walk-forward replay reports out-of-sample results, and seeded scenarios report ending equity, drawdown and market exposure. 0.20.0 values dated holdings and shows where coverage is incomplete.
